# Task

## Product description

**Schematics AI Tutor** is a web app where entry-level learners learn basic electricity by building circuits on an interactive grid. The learner builds the circuit, a deterministic evaluator checks it, and Claude acts as a tutor: it gives feedback, hints and an assessment of the learner's direction.

The goal is understanding, not task completion. The learner should leave able to reason about why a circuit behaves the way it does.

**Target user:** a beginner with little or no electronics background, such as a student, a hobbyist starting with Arduino, or a career switcher.

## Concept of operations

### Actors

| Actor | Role |
|---|---|
| Learner | Builds circuits on the grid and responds to the tutor |
| Grid editor | Lets the learner place and remove components and wires; produces the grid |
| Evaluator | Deterministic. Converts the layout to a netlist, computes voltages and currents, and checks them against the level goal |
| Claude task generator | Proposes the next task, choosing its concept and complexity from the learner's skill level and task history. The evaluator validates each proposal and computes its targets. |
| Claude tutor | Reads the level, the learner's circuit and the evaluator's results, then gives feedback, hints and an assessment of the learner's direction |

### Operating principles

1. **The learner does the work.** The tutor never places components or hands over the solution.
2. **The evaluator is the source of truth.** Every electrical value shown to the learner or given to Claude comes from the evaluator, never from the model.
3. **Claude reasons about the learner, not the circuit.** It turns evaluator results into teaching: what the learner seems to believe, what to try next, and why.

### Levels

The learner has a skill level that starts at 1 and goes up by one with each solved task. The first task is curated. After that, Claude generates each task, choosing its concept and complexity from the skill level and the history of solved tasks. Each level defines:

- a starting grid (empty or partially built)
- the available components (resistors, voltmeters, wires, power source)
- a goal: a target voltage or current at a specific point in the circuit
- the concept being taught

## Workflow

1. The learner receives a level, either curated or generated by Claude and validated by the backend. They see the goal, the starting board and the available components.
2. The learner places components and wires on the grid.
3. On every edit, the evaluator builds the netlist and computes the values, and meter readings update live. It reports one status, from `short_circuit` through `near_target` to `solved`, with live readings of every placed meter and the issues behind the status.
4. When the learner pauses (a burst of quick edits counts as one), the backend sends Claude the snapshots since its last call: each grid, its graph and its evaluation. Claude reacts to what the learner just did. A misstep gets a nudge, such as "this wire end isn't touching anything", and progress gets encouragement.
5. The learner can also ask for a check or a hint, or write a message. Claude responds with feedback and, if asked, the next hint.
6. The learner revises and repeats from step 2, or moves on when the status is `solved`: the skill level goes up by one, and the next task is served. That level was pre-generated in the background.

## Major constraints

| Constraint | Implication |
|---|---|
| Built in under a day | One core loop done well; a handful of levels; minimal polish |
| Must be deployed and usable by reviewers | Public URL; Claude API key stays server-side; basic rate limiting |
| Must use the Claude API | Claude provides the tutoring layer |
| Claude must not be trusted for electrical math | Deterministic evaluator; Claude only interprets its output |
| Entry-level audience | Simple DC circuits only (resistors, sources, meters); plain language, no jargon without explanation |
| Enhance, not replace, human agency | No auto-solve; hints escalate only when the learner asks |
| Stack | Python backend; JavaScript/React + three.js frontend |
